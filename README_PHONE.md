# التشغيل من الهاتف فقط (بدون لابتوب)

## الخيار الأسهل: Termux (مجاني)
1. ثبّت **Termux** من متجر **F-Droid** (نسخة Play Store قديمة).
2. افتح Termux وانسخ هذه الأوامر سطراً سطراً:
```bash
pkg update -y
pkg install -y python unzip
termux-setup-storage
cp /sdcard/Download/reverse-engineering-lab.zip ~/
unzip reverse-engineering-lab.zip
cd reverse-engineering-lab
python run_on_phone.py
```
3. النتيجة الصحيحة:
```
قبل التعديل: Access Denied - Normal User Mode
بعد التعديل: Welcome Admin - All Permissions Granted
```

## الخيار الثاني: Pydroid 3 (مجاني من Play Store)
1. فك ضغط الملف من مدير الملفات.
2. افتح مجلد المشروع في Pydroid وافتح `run_on_phone.py` واضغط زر التشغيل الأصفر.

## إذا لم تستطع التشغيل يوم التسليم
سلّم الملف المضغوط كما هو مع هذا الشرح. التقارير الجاهزة أصلاً داخل `reports/`
 ونتيجة الاختبار الحقيقية موثقة في `README.md` — افتحها من الهاتف واشرح الخطوات للدكتور.
